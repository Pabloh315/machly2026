Integración móvil

Machly API

Una sola API y una sola base SQLite para web, Android y cualquier cliente autorizado. Las rutas privadas usan JWT mediante el encabezado Authorization.

Base URL

Documentación importable: openapi.yaml · Estado: /api/health

Autenticación

POST/api/auth/registerCrear cuenta cliente o propietario
POST/api/auth/loginObtener token JWT y usuario
GET/api/auth/meValidar token y obtener perfil

Equipos

GET/api/equipmentCatálogo, búsqueda, fechas y filtros
GET/api/equipment/:idDetalle, reseñas y fechas ocupadas
POST/api/equipmentPublicar como propietario
PUT/api/equipment/:idEditar publicación propia

Reservas y actividad

GET/api/bookingsReservas del cliente
POST/api/bookingsSolicitar reserva sin solapamientos
PATCH/api/bookings/:id/statusAceptar, rechazar, entregar o completar
GET/api/favoritesFavoritos del usuario
POST/api/reviewsCalificar reserva completada
